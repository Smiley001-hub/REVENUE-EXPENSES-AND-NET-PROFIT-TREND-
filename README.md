# Revenue, Expenses and Net Profit Trend Analysis

## Overview
This project analyzes three years of company revenue, expenses and net profit.

## Tools Used
- Microsoft Excel
- Data Storytelling
- Charts and Dashboard Design
- Microsoft Word

## Objectives
- Compare yearly revenue trends
- Identify profit and loss patterns
- Communicate insights through storytelling

## Key Insights
- Revenue does not always translate into higher profit.
- Expenses largely determine profitability.
- Seasonal fluctuations affected performance.
